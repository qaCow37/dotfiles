# nix
My nix flake containing my minimal system configuration and my home manager configuration.

# The System
The system configuration is supposed to be very minimal and install no packages or programs.
The only things the system configuration does it provide a minimal system that boots straight into the TTY.

# Home Configuration
This is my life. It contains all programs I need and configures them.
It installs NiriWM so i can launch it straight from TTY after logging in.

# Assets
The assets folder only contains placeholder. Each placeholder is just an image of a single black pixel.
I am not allowed to distribute the assets I am using and as such download them manually.
